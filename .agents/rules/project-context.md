# AUTOPILOT Opencode Plugin — Project Context

## Identity
An opencode plugin that enables autonomous AI coding agents to run iterative development loops — plan, code, review, test, commit — with state persistence, backpressure, and multi-model support.

## Directory Structure
- `.agents/documents/requirements/` — P1-P2 outputs (problem ID, personas, value prop, market sizing, competitor analysis, assumptions, hypotheses, feasibility, MVP scope, feature priorities, requirements, stories, AC, BDD, technical designs, edge cases, feature decomposition, risk register, cost estimates, backlog)
- `.agents/documents/design/` — P3-P4 outputs (architecture, domain, database, API, flows, wireframes, components, design tokens)
- `.agents/documents/tasks/` — P7 outputs (roadmap, sprint manifest, sprint plans, allocation audit)
- `.agents/documents/application/` — P8 outputs (README, modules/, api/, testing/, manifest, cross-links, traceability audit)

## Constraints
- Phase 1 (P0-P8A): Documentation only — no code generation
- Phase 2 (P9-P10-GF): Implementation tasks — not yet started
