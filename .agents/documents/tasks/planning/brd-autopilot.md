# Business Requirements Document: AUTOPILOT Plugin

## Business Case
Developers using AI coding assistants lose 30-50% of session productivity to context drift, manual iteration, and state loss. AUTOPILOT eliminates these inefficiencies by providing persistent state, automated iteration loops, and quality gates within the opencode plugin ecosystem.

## Target Market
- Primary: Solo developers using opencode (7.5M monthly active users)
- Secondary: Engineering teams seeking standardized AI coding workflows
- TAM: $2.2B annually | SAM: $384M | 3-year SOM: $115M

## Revenue Model
- Open-source core plugin (free)
- Enterprise support: $20/mo/seat (audit logs, SSO, custom gates)
- Year 1: Community adoption | Year 2: Enterprise monetization

## Success Metrics
- 10K+ plugin installs in Year 1
- 60%+ weekly active users
- 30%+ reduction in time-to-PR for AI-assisted features
