# Cost Estimation: AUTOPILOT Plugin

## Development Costs

| Category | Year 1 | Year 2 |
|---|---|---|
| Engineering (2 FTE at $120K) | $240,000 | $250,000 |
| Contractor/consulting | $25,000 | $15,000 |
| AI API costs (dev + beta) | $5,000 | $20,000 |
| Infrastructure (CI, storage) | $3,000 | $10,000 |
| Open-source hosting/community | $2,000 | $5,000 |
| **Total** | **$275,000** | **$300,000** |

## Cost Per User (Projected)

| Metric | Year 1 (6,400 users) | Year 2 (19,200 users) |
|---|---|---|
| Infrastructure cost/user | $0.47/user | $0.52/user |
| Support cost (estimated) | $2.00/user | $1.50/user |
| **Total cost/user** | **$2.47/user** | **$2.02/user** |

## Key Cost Drivers
- **Engineering** (87% of Year 1 costs): 2 FTE is the minimum viable team for plugin development
- **AI API costs**: Low in Year 1 (dev only); grows with user adoption in Year 2
- **Infrastructure**: Minimal — plugin is self-contained; no external servers required for core functionality

## Funding Recommendation
- Year 1: Open-source with community contributions + developer time allocation
- Year 2: Evaluate enterprise support tier ($20/mo/seat) for sustainability
