# Value Proposition: AUTOPILOT Opencode Plugin

## Primary Value Proposition

> For developers using AI coding assistants who lose productivity to context drift and session decay, AUTOPILOT is an opencode plugin that provides persistent state, iterative refinement loops, and multi-model orchestration. Unlike manual session management or stateless AI tools, AUTOPILOT maintains working context across iterations, automatically runs quality gates (lint → test → review), and enables true autonomous multi-step feature completion.

## Supporting Benefits

- **Developers ship features faster** — describe a feature once, AUTOPILOT iterates through plan/code/review/test/commit autonomously, reducing multi-round prompting by 80%.
- **Code quality improves consistently** — every iteration passes through linters, type checks, tests, and code review before commit, catching issues the developer would otherwise catch post-hoc.
- **Multi-model workflows become seamless** — use the best model for each phase (Claude for planning, GPT-4 for coding, o3 for review) with automatic context transfer between models.

## Elevator Pitch

Developers lose 30-50% of AI session time to context management and manual iteration. AUTOPILOT is the first opencode plugin that gives AI coding agents persistent memory, automated quality gates, and multi-model orchestration — so you describe a feature once and it ships as a reviewed, tested PR.
