# Design System Tokens: AUTOPILOT Plugin

## Color Tokens (CLI)
| Token | Usage | ANSI Code |
|---|---|---|
| color.success | ✓ Pass/complete | Green (32) |
| color.error | ✗ Failure/error | Red (31) |
| color.warning | ⚠ Warning | Yellow (33) |
| color.info | ℹ Information | Blue (34) |
| color.highlight | File names, important values | Cyan (36) |
| color.muted | Metadata, timestamps | Gray (90) |
| color.separator | Delimiters | Dim (2) |

## Typography
- Font: Terminal monospace (system default)
- Weight: Normal (no bold/italic — rely on color and symbols)
- Decoration: Underline for clickable/selectable items (where supported)

## Spacing
- Indent: 2 spaces per nesting level
- Section padding: 1 blank line between sections
- Table padding: 2 spaces between columns

## Iconography
| Icon | Meaning |
|---|---|
| ● | Active/in-progress |
| ✓ | Completed/passed |
| ✗ | Failed |
| ⚠ | Warning/attention |
| ℹ | Information |
| ⏳ | Running/waiting |
