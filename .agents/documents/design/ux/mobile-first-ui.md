# Mobile-First UI Specification: AUTOPILOT Plugin

## Priority
AUTOPILOT is primarily a CLI plugin. Mobile-first is NOT a priority for MVP.

## Future Mobile Considerations
- Terminal app on iPad (via SSH/iSH): responsive layout rules apply
- Mobile web dashboard for monitoring session status (read-only): Future phase
- Push notifications for session completion: Future phase

## Current Scope
- CLI is the only interface for MVP
- All interactions via keyboard
- Session output viewable in any terminal (including mobile terminal apps)
