# Accessibility Test Cases: AUTOPILOT Plugin

## CLI Accessibility

| Criteria | Test | Standard |
|---|---|---|
| Color-only indicators | Status should also use symbols (✓, ✗, ⚠) | WCAG 1.4.1 |
| Keyboard navigation | All interactions via keyboard | WCAG 2.1.1 |
| Screen reader | Text output readable by terminal screen readers | — |
| Contrast | Text/bg contrast ratio ≥ 4.5:1 | WCAG 1.4.3 |
| Error identification | Errors described in text, not just color | WCAG 3.3.1 |
